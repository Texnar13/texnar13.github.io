# Портфолио texnar13

Статический сайт в тёмной теме, вдохновлённой Material Design 3. Постоянный вводный блок и три переключаемых направления.

Откройте index.html в браузере. Установка зависимостей и сборка не нужны. Manrope загружается из Google Fonts; без интернета используется системный шрифт.

## Наполнение

- index.html — тексты, ссылки, технологии и карточки. Карточки явно отмечены как заготовки: замените своими проектами, изображениями и ссылками.
- style.css — оформление и адаптивная сетка.
- script.js — вкладки и текущий год.

Ссылки на направления: #android, #3d, #hardware. Вкладки поддерживают стрелки влево/вправо, Home и End.

## GitHub Pages

Загрузите файлы в основную ветку репозитория texnar13.github.io. В Settings → Pages выберите Deploy from a branch, основную ветку и / (root). Сайт будет доступен по адресу https://texnar13.github.io/. Все локальные ресурсы используют относительные пути.
